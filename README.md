# YouTube Shorts 量産パイプライン — 撮って投げるだけ

[X_Autopost](https://github.com/matrixtask/X_autopost) と同じインタビュー駆動の仕組みで、
**質問に答える動画を撮るだけ**でYouTubeショートが量産され、撮りためたショートは
1本のまとめ動画にもなるシステムです。

編集（変な間のカット・字幕・ツッコミ・挿絵・切り出し）は全部Claudeとffmpegがやります。

## 毎日のルーティン（あなたがやること）

1. **朝、Slackに撮影台本が届く**（質問5問＋ネタ指示。テーマは 定番 / 時事 / ネタ から自動選定）
2. **スマホを縦にして、質問に答える動画を撮る**（1本通しでOK。言い直し・変な間・噛みは気にしない）
3. **動画をPCの `workspace/inbox/` に入れて `ytshorts run`**
4. 終わり。あとは全部自動:
   - 文字起こし（単語タイムスタンプ付き）
   - Claudeが編集プランを作成 → 1回答=1ショートで切り出し
   - 沈黙・言い直し・フィラーをカットしてテンポを作る
   - 字幕＋フックテキスト＋ツッコミ字幕を焼き込み、挿絵イラストを挿入
   - ショートごとに品質採点（品質ゲート）→ 合格分だけ `workspace/shorts/` にストック
   - 結果はSlackに通知
5. 溜まったら **`ytshorts compile`** で1本のまとめ動画（16:9・チャプター付き）

## 全体像

```
 朝8時                随時                        随時（ローカルPC）
┌────────────┐  スマホで撮影   ┌──────────────┐   ┌────────────────────────┐
│ 撮影台本生成  │ ───────────▶ │ 動画を inbox へ │ ─▶│ 文字起こし → 編集プラン     │
│ 質問+ネタ指示 │   （Slack）    │ ytshorts run  │   │ → 間カット → 字幕・挿絵     │
└────────────┘                └──────────────┘   │ → 品質ゲート → ショート量産  │
       │                                          └────────────────────────┘
       │                                                     │ ytshorts compile
       └── スプレッドシート（台本DB）/ Slack通知 ──┐               ▼
                                              └──── まとめ動画（16:9・チャプター付き）
```

- **撮影台本**: 質問ごとに「答え方のコツ」と「ネタ指示」（例: ここで一回真顔で沈黙）付き。
  スレッドへの返信は次の台本づくりのヒントとして記憶されます
- **変な間は全部カット**: 単語タイムスタンプから沈黙を検出して自動カット。
  言い直しやフィラー（えー、あのー）はClaudeが指定してカット
- **挿絵**: Claudeが描くフラットなSVGイラストをPNG化して話の山場に挿入
- **品質ゲート**: ショートごとに0-100点で採点し、閾値（既定70点）未満は
  レンダリングせずプランだけ残す。`plan.json` を直して再実行もできる

## リポジトリ構成

```
gas/        撮影台本システム（Google Apps Script + Slack + スプレッドシート）
pipeline/   編集パイプライン（Python + faster-whisper + Claude + ffmpeg）
```

セットアップ手順:

- 台本がSlackに届くようにする → **[gas/README.md](gas/README.md)**
- ローカルの編集パイプライン → **[pipeline/README.md](pipeline/README.md)**

GAS側がなくてもパイプライン単体で動きます（動画を入れて `ytshorts run` するだけ）。
連携すると「どの質問に答えた動画か」が編集プランに渡り、結果がSlackに届きます。
